The console's action button. One `primary` (blue) per view; `outline` for the secondary actions beside it; `accent` (orange) only on screens that use the navy shell.

```jsx
<Button variant="primary" icon="plus">Add Truck</Button>
<Button variant="outline" icon="download">Export</Button>
<Button variant="outline" iconRight="chevron-down">More Actions</Button>
<Button variant="danger" icon="trash-2">Cancel Verification</Button>
```
