Renders one Lucide glyph in the Trukkas Admin icon style (1.6-ish stroke, 24 box, currentColor). Use for every icon in the console — never emoji, never a hand-drawn SVG.

```jsx
<Icon name="truck" size={18} />
<Icon name="circle-alert" size={16} color="var(--tk-danger)" />
```

Glyphs used across the console: layout-dashboard, package, truck, users, map-pin, wallet, receipt, shield-check, file-text, chart-column, settings, life-buoy, bell, search, chevron-down, chevron-right, chevron-left, ellipsis-vertical, plus, download, upload, filter, eye, pencil, trash-2, circle-check, circle-alert, triangle-alert, clock, calendar, copy, external-link, arrow-up-right, arrow-right, arrow-up, arrow-down.
